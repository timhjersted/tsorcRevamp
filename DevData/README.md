# Developer Data

`DevData` contains developer-facing inventories, spreadsheets, and Markdown references extracted
from the mod. These files document source data; they are not runtime assets loaded by tModLoader.

Subject-specific data belongs in a named subdirectory such as `EnemySpawns/` or `Weapons/`.
Generated subdirectories should identify their generator and should be updated through that tool
rather than edited by hand.

The enemy spawn reports are regenerated by `Scripts/GenerateDevData/EnemySpawns`.
Its detailed inventory is provided as responsive HTML because the number and length of spawn
conditions are not readable within a normal Markdown content column.
The biome-pool HTML intentionally presents only phase, biome, enemy, and weight; use the detailed
inventory when exact conditions are needed.
